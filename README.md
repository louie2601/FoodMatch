# Food Match
A web repository for food research with machine-learning similarity detection (Django, PostgreSQL, Tailwind CSS).

The project folder and Django project are named `FoodHub` / `foodhub`; the system itself is called Food Match.

---

## Setup

1. Create a virtual environment (recommended):

   ```powershell
   C:/Users/Personal Laptop/AppData/Local/Programs/Python/Python312/python.exe -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

2. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

3. Apply database migrations:

   ```powershell
   python manage.py migrate
   ```

4. Run the development server:

   ```powershell
   python manage.py runserver
   ```

5. Open http://127.0.0.1:8000 in your browser.

## Key Files & Folders Explanation

### 📁 `core/` (Main Django App)
This is where almost all your app's code lives!

| File/Folder      | Purpose                                                                 |
|------------------|-------------------------------------------------------------------------|
| `models.py`      | Define your database tables here (e.g., `FoodItem`, `ResearchPaper`).  |
| `views.py`       | Define "views" that handle user requests and return responses.         |
| `urls.py`        | Map URLs to views (e.g., `/` → `home` view).                           |
| `admin.py`       | Register models to show up in Django Admin.                            |
| `templates/`     | HTML templates for your pages (uses Django Template Language).         |
| `static/`        | CSS, JavaScript, images, and other static assets.                      |

### 📁 `foodhub/` (Project Config)
This is the "project" folder that ties everything together!

| File             | Purpose                                                                 |
|------------------|-------------------------------------------------------------------------|
| `settings.py`    | Project-wide settings (DEBUG mode, installed apps, database config).   |
| `urls.py`        | Main entry point for URL routing (includes `core/urls.py`).             |

### 📁 `media/` (User Uploads)
Use this folder to store user-uploaded files (e.g., profile pictures, food images) when you add that functionality later!

## Development Tips
- Always make sure the virtual environment is **activated** before running Django commands!
- After changing `models.py`, run: `python manage.py makemigrations` then `python manage.py migrate`!
- To access Django Admin, create a superuser with: `python manage.py createsuperuser`!
